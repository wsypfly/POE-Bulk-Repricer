POE标价工具
============

运行方式
--------
1. 开源版：先安装 AutoHotkey v1，再执行：
   python -m pip install -r requirements.txt
   然后双击 POE标价工具.ahk。

2. AHK分享版：安装 AutoHotkey v1 后，双击 POE标价工具.ahk。
   该版本自带 market_detect_items.exe，不需要安装 Python。

3. 全打包版：解压后双击 POE标价工具.exe。
   该版本不需要安装 Python 或 AutoHotkey。

使用步骤
--------
1. 打开流放之路，进入要改价的仓库页。
2. 先用“检测预览”或默认 F4，确认能识别到物品。
3. 设置改价规则后，使用“批量改价”或默认 F3。
4. 批量改价会实际输入新价格并回车，请先小范围测试。

规则说明
--------
- 打折模式：8 表示原价 * 0.8；8.5 表示原价 * 0.85。
- 统一加减：-5 表示原价减 5；+5 或 5 表示原价加 5。
- 取整方式支持四舍五入、向下取整、向上取整。
- 最终价格小于 1 时，会按 1 标价。
- 打折小于 5 折会二次确认；小于 1 折会强烈确认。
- 统一减价会在执行前确认。

文件说明
--------
- settings.ini：保存颜色、改价规则和热键，保存后立即生效。
- market_detect_items.tsv：最近一次检测到的物品列表。
- market_discount_debug.txt：最近一次检测 debug。
- market_discount_capture.png：最近一次检测截图。
- market_discount_log_*.csv：批量改价日志。

调试模式
--------
- 默认关闭调试模式，不会在运行目录生成 png、txt、csv、tsv 调试文件。
- 需要排查识别或点击问题时，在界面勾选“调试模式”并保存。
- 调试模式开启后，会保留检测 TSV、debug TXT、截图 PNG 和改价 CSV 日志。

常见问题
--------
- F4 识别为 0：确认仓库里已经搜索“物品”，或调整边框颜色。
- 复制价格失败：确认右键物品后价格输入框会选中当前数字。
- 热键无效：确认两个热键不相同，且没有被其他软件占用。
